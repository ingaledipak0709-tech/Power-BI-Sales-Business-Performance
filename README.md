# Power BI Sales & Business Performance Dashboard

## Project Overview
This project uses Microsoft Power BI to analyze sales performance, product profitability, customer behavior, and shipping operations through an interactive dashboard.

The goal is to turn raw data into meaningful insights that support business decision-making.

## Dashboard Pages

### 1. Executive Overview
Provides a high-level view of key business performance indicators.

### 2. Product Profitability
Helps analyze product performance, sales, and profitability.

### 3. Customer Intelligence
Explores customer purchasing patterns and sales trends.

### 4. Shipping & Operations
Focuses on shipping performance and operational efficiency.
